# Self-hosted interface fonts

Downloaded unchanged from Google Fonts on 2026-10-28. Both families use the SIL Open Font License 1.1; the accompanying license files are distributed with static publications and the administration assets.

The original stylesheet is https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=IBM+Plex+Mono:wght@400;500&display=swap . No runtime request to Google Fonts is required.

DM Sans v17 provides the variable weight range 400 to 700 in Latin and Latin Extended. It does not contain Cyrillic; the interface uses its system sans fallback for those characters. IBM Plex Mono v20 is distributed at its real regular (400) and medium (500) weights, in Latin and Cyrillic subsets. The Cyrillic subset includes Russian, Ukrainian and Belarusian characters; other scripts use the configured system fallback.
