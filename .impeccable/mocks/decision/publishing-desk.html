OVERVIEW

Build your documentation

Write guides, tutorials, runbooks and architecture notes in Markdown. Keep API reference next to the source that defines it.

Create a project

Start the development environment to preview your documentation and work on your content in Studio.

Terminal
$task dev

Your documentation and its source files stay together in one project.

Write your first page

Add a Markdown page, then include it in your project manifest. Use the title readers will see in navigation.

Manifest
{
  "version": 1,
  "title": "My documentation",
  "pages": [{ "title": "Overview", "path": "index.md" }]
}
