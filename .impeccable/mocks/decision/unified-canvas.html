Build your documentation

Write guides, tutorials, runbooks and architecture notes in Markdown. Keep API reference next to the source that defines it.

Edit this pageCopy page

Create a project

Start the documentation site locally, then open the CMS to manage your content. The development environment includes everything you need to begin.

Terminal
$ task dev
$ docker compose up --build -d --wait cms

Write your first page

Add a Markdown page to your project, or open Studio to write in the CMS. Organize your guides with navigation and keep drafts ready for review.

Your content stays yours. Work with Markdown files and Git, or manage pages, drafts and history in Studio.

Publish documentation

Build your documentation from Markdown, HTML, Protobuf and OpenAPI sources. Choose a theme and deploy the generated site.
